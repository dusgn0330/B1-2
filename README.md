## 1. 브랜드 아이덴티티 및 캠페인 정의

- **브랜드명:** 거제도 (GEOJE TRIP)
- **타겟:** 반복되는 일상과 업무에 지친 20~40대 직장인 및 짧은 휴식 여행을 원하는 국내 여행객
- **톤앤매너:** 시네마틱, 감성적, 차분함, 힐링. 초반은 어둡고 차갑게, 거제 도착 후 밝고 따뜻하게 전환
- **USP:** 도시의 바쁜 일상에서 가까운 거제의 바다와 노을을 통해 짧은 시간에도 휴식과 감정적 전환을 경험하게 하는 여행지
- **톤 예시 문장:** 도입부는 짧고 건조하게 — “참 바쁜 하루 끝” / 전환 이후는 부드럽고 따뜻하게 — “당신이 쉬어야 할 곳”
- **광고 목적:** 인지 + 방문 관심 유도
- **캠페인 목표:** 거제 바다와 자연의 휴식 이미지를 각인시켜 브랜드 인지도와 여행 관심도를 높인다.
- **핵심 메시지(한 문장):** “거제야호, 바다가 당신을 기다립니다”

## 2. 전체 서사 및 제작 전략

도시의 피로에서 거제의 휴식으로 감정이 이동하는 순간을 8초 안에 압축했습니다. Scene 1의 차가운 사무실과 Scene 2~3의 따뜻한 바다를 대비시켜 메시지를 직관적으로 전달합니다.

**서사 구조:** 문제 제시 → 감정 전환 → 해결/제안

```
Scene 1 (0~2초)   바쁜 일상      어두운 사무실, 지친 직장인
Scene 2 (2~5초)   휴식으로 전환   거제 해변, 두 팔 벌린 남자
Scene 3 (5~8초)   브랜드/CTA     노을 + GEOJE TRIP 로고 + 슬로건
```

### 사용 도구 목록

| 구분 | AI 도구 | 사용 목적 | 선택 이유 |
|---|---|---|---|
| 이미지 생성 | OpenAI Sora 2 | 인물·사무실·해변·노을 등 시각 요소 생성 | 한 플랫폼에서 장면의 분위기와 시각 톤을 일관되게 유지 |
| 비디오 생성 | OpenAI Sora 2 | 인물 행동, 카메라 움직임, 장면 전환 및 영상 생성 | 짧은 광고를 한 번에 영상화하고 인물·공간 연출을 통합 |
| 오디오 생성 | OpenAI Sora 2 | 내레이션 3구간 및 잔잔한 BGM 생성 | 영상과 음성·음악의 타이밍과 분위기를 동시에 맞춤 |

### 오디오 프로필

- **내레이션:** 차분하고 낮은 톤의 한국어 음성, 씬당 한 문장으로 짧게 (Scene 1~3 각 1구간, 총 3구간)
- **BGM:** 잔잔하고 따뜻한 힐링 계열, 0~8초 끊김 없이 이어지며 Scene 3 후반에 슬로건 내레이션과 겹치지 않도록 낮은 볼륨 유지

### 도구 선택 기준 (우선순위)

1. **톤·캐릭터 일관성** (최우선): 사무실 → 해변 → 노을이 한 작품처럼 이어져야 하므로 한 플랫폼(Sora 2) 사용
2. **품질:** 감정 전환(차가움 → 따뜻함)이 보이는 수준의 시네마틱 품질
3. **속도·비용:** 8초 분량이라 재생성 횟수를 줄이는 것으로 관리 (아래 크레딧 전략 참고)

### T2I vs I2V 선택

| 방식 | 장점 | 단점 |
|---|---|---|
| T2I (텍스트→이미지) 후 I2V (이미지→영상) | 키비주얼을 먼저 확정해 영상 크레딧 낭비를 줄임, 인물·구도 고정에 유리 | 두 단계라 시간이 더 들고 도구가 나뉘면 톤이 어긋날 수 있음 |
| T2V (텍스트→영상 직접 생성) | 한 번에 움직임·음성까지 생성, 공정이 단순 | 결과 편차가 크고 재생성 시 크레딧 소모가 큼 |

**이 프로젝트의 선택 기준:** 8초·3씬의 짧은 광고이고 톤 일관성이 최우선이므로, 이미지와 영상을 모두 Sora 2에서 만들어 도구 간 불일치를 없앴습니다. 씬별 PNG는 각 씬의 키프레임(확정 비주얼)으로 보관합니다.

### Scene 3 (수정 있음)

**수정 전**

```
장면3 (5~8초)
- 거제 바다 노을 전경
- 화면 중앙에 GEOJE TRIP 로고
- 아래에 "거제야호! 바다가 당신을 기다립니다"
```

**수정 후**

```
장면3 (5~8초)
- 거제 바다 노을 전경
- 화면 중앙에 GEOJE TRIP 로고
- 아래에 "거제야호! 바다가 당신을 기다립니다"
- 깔끔하게 페이드아웃
```

**수정 이유**

1. 수정 전 프롬프트로는 영상이 끝나는 지점이 너무 갑작스럽게 끊기는 느낌이어서, 페이드아웃으로 자연스럽게 마무리되도록 바꾸고 싶었음.
2. 엔딩의 완성도를 높이기 위해 “4K 화질, 영화같은 느낌으로 만들어줘”를 함께 추가함.
3. 결과적으로 Scene 3이 단순한 노을 풍경에서, 브랜드와 핵심 메시지를 남기며 부드럽게 끝나는 광고 엔딩으로 발전함.

**출력에 미친 영향(한 줄):** 마지막 컷이 갑자기 끊기지 않고 페이드아웃으로 여운을 남기며 마무리됨.

## 5. 제작 파이프라인 (기획 → 생성 → 검수 → 통합)

| 단계 | 핵심 산출물 | 담당 |

**검수 체크리스트**

- [ ] 씬 3개 모두 720×1280, 9:16, 30fps
- [ ] Scene 1·2의 인물이 동일한 사람으로 보임
- [ ] 색감이 차가움 → 따뜻함으로 자연스럽게 전환됨
- [ ] 내레이션과 BGM의 볼륨 균형 (대사가 BGM에 묻히지 않음)
- [ ] 마지막 3초(5~8초)에 GEOJE TRIP + 슬로건이 가려지지 않고 노출됨
- [ ] 총 길이 10초 이내, 오디오·비디오 싱크 이상 없음

**통합 편집 절차:** 컷 순서 배치(1→2→3) → 내레이션/BGM 레벨 조정 → 간단한 색보정 → 최종 H.264/AAC 인코딩. 편집은 통합 용도로만 제한하고 핵심 비주얼·오디오는 AI 생성물을 유지합니다.

## 6. 일관성 유지 (캐릭터·스타일)

- **캐릭터:** 별도 레퍼런스 파라미터 대신, 한 플랫폼(Sora 2)에서 생성하고 Scene 2 프롬프트에 “같은 남자”를 명시해 동일 인물을 유지합니다. 재생성이 필요하면 인물 외형(30대 남성, 셔츠 차림)을 프롬프트에 그대로 반복합니다.
